# Analog Electronics Lab Experiments

This repository contains the software experiments completed as part of the 3rd-semester Analog Electronics Laboratory at IIIT Kottayam. All simulations and designs are performed using Cadence Virtuoso.

## Experiments Completed Till Date

1. **Familiarisation of Design Flow:** Introduction to the Cadence Virtuoso environment and basic design flow steps.
2. **NMOS Characterization:** Analysis and characterization of NMOS transistor parameters.
3. **RF Low Pass Filter:** Design and simulation of an RF Low Pass Filter.
